# 📚 บทเรียน Machine Learning: Stroke Prediction Dataset

## 📈 LAB 1: Regression
บทเรียนนี้จะเน้นไปที่การสร้างโมเดล Machine Learning เพื่อทำนายผลลัพธ์ที่เป็น **ตัวเลขต่อเนื่อง (Continuous Data)**

* **Simple Linear Regression:** การสร้างโมเดลทำนายโดยใช้ข้อมูลอ้างอิง (Feature) เพียง **ตัวแปรเดียว** (เช่น ใช้ค่า BMI อย่างเดียวเพื่อทำนายอายุ) เป็นพื้นฐานของการสร้างสมการเส้นตรง
* **Multiple Linear Regression:** การสร้างโมเดลทำนายโดยใช้ข้อมูลอ้างอิง **หลายตัวแปร** ร่วมกัน (เช่น ใช้ทั้งค่า BMI, ระดับน้ำตาลในเลือด และสถานะโรคหัวใจ เพื่อทำนายอายุ) ซึ่งมักจะให้ผลลัพธ์ที่แม่นยำและใกล้เคียงความเป็นจริงมากกว่า
* **Age Prediction:** คือเป้าหมายหลักของการทดลองใน LAB นี้ นั่นคือการประยุกต์ใช้โมเดล Regression ทั้ง 2 แบบ เพื่อ **ทำนายอายุ (Age)** ของบุคคลจากข้อมูลสุขภาพ

## 📊 LAB 2: Classification
บทเรียนนี้จะเปลี่ยนรูปแบบจากการทำนายตัวเลข เป็นการทำนายเพื่อจัดกลุ่ม, แยกประเภท หรือจัดหมวดหมู่ (เช่น ใช่/ไม่ใช่, ชาย/หญิง)

* **Preparing Classification Data:** ขั้นตอนการเตรียมและทำความสะอาดข้อมูลให้พร้อมก่อนนำไปสอนโมเดล เช่น การแปลงข้อมูลที่เป็นตัวอักษร (Male/Female) ให้เป็นตัวเลข (0/1) หรือการตัดข้อมูลที่ไม่สมบูรณ์ทิ้งไป
* **Decision Boundary Visualization:** การสร้างกราฟเพื่อแสดงภาพ **"เส้นแบ่งขอบเขตการตัดสินใจ"** ทำให้เราเห็นภาพชัดเจนว่าโมเดลลากเส้นแบ่งกลุ่มข้อมูล (เช่น แบ่งระหว่างเพศชายและหญิง) อย่างไร
* **Logistic Regression:** คือชื่อของอัลกอริทึม (Algorithm) ยอดนิยมที่ใช้สำหรับการทำ Classification (ถึงแม้ชื่อจะมีคำว่า Regression แต่หน้าที่หลักของมันคือการจำแนกหมวดหมู่)
* **Gender Prediction:** เป้าหมายหลักของ LAB นี้ คือการใช้โมเดล Logistic Regression เพื่อทำนาย **เพศ (Gender)** ของบุคคล โดยประเมินจากปัจจัยอื่นๆ (เช่น อายุ และ BMI)
* **Confusion Matrix:** ตารางประเมินผลการทำนาย ที่ช่วยแจกแจงให้เราเห็นว่า โมเดลทายถูกกี่ครั้ง และทายผิดพลาดในลักษณะไหนบ้าง (เช่น ทายผู้ชายเป็นผู้หญิงกี่คน, ทายผู้หญิงเป็นผู้ชายกี่คน)

## ⚖️ LAB 3: Model Comparison
บทเรียนสุดท้ายนี้จะเน้นไปที่การวิเคราะห์ว่าโมเดลที่เราสร้างขึ้นมานั้นมีประสิทธิภาพ "ดีแค่ไหน" และควรเลือกใช้เครื่องมืออย่างไรให้เหมาะสม

* **Simple vs Multiple Linear Regression:** การนำผลลัพธ์ของโมเดลที่ใช้ตัวแปรเดียว มาเปรียบเทียบกับโมเดลที่ใช้หลายตัวแปร เพื่อพิสูจน์ว่าการให้ข้อมูลโมเดลมากขึ้น ช่วยให้การทำนายดีขึ้นจริงหรือไม่
* **Training vs Testing Performance:** การเปรียบเทียบความแม่นยำระหว่าง "ตอนสอนโมเดล (Train)" กับ "ตอนทดสอบด้วยข้อมูลใหม่ (Test)" เพื่อตรวจหาภาวะ **Overfitting** (โมเดลท่องจำข้อมูลเก่งเกินไป แต่พอเจอข้อมูลใหม่ในชีวิตจริงกลับทำนายผิดพลาด)
* **Regression vs Classification:** การสรุปความแตกต่างของศาสตร์ทั้ง 2 รูปแบบ เพื่อให้คุณสามารถเลือกใช้เครื่องมือได้ถูกต้องตามลักษณะของโจทย์ (เป้าหมายเป็นตัวเลข = Regression / เป้าหมายเป็นหมวดหมู่ = Classification)
* **Model Performance Metrics:** การเรียนรู้ตัวชี้วัดความแม่นยำต่างๆ เช่น MSE และ R-squared สำหรับโมเดลแบบ Regression หรือค่า Accuracy (ความแม่นยำรวม) สำหรับโมเดลแบบ Classification
