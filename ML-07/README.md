# LAB 07 - Convolutional Neural Network (CNN) on a Custom Dataset
โปรเจกต์นี้เป็นการทดลอง Machine Learning ในส่วนของการสร้างและพัฒนาโมเดล Convolutional Neural Network (CNN) สำหรับงานจำแนกประเภทรูปภาพ (Image Classification) โดยเปิดโอกาสให้เลือกชุดข้อมูลตามความสนใจ พร้อมทั้งเปรียบเทียบประสิทธิภาพภายใต้จำนวนรอบการฝึก (Epochs) และสถาปัตยกรรมของโมเดลที่แตกต่างกัน

## 1. โครงสร้างโปรเจกต์
dataset/ : โฟลเดอร์เก็บข้อมูลภาพที่ใช้ในการทดลอง
models/ : บันทึกไฟล์โมเดล CNN ที่ผ่านการฝึกแล้ว
outputs/ : จัดเก็บกราฟผลลัพธ์และไฟล์สรุปผลการประเมิน
main.py : ไฟล์รันหลักสำหรับควบคุม Pipeline ทั้งหมดตั้งแต่โหลดข้อมูล เทรน และประเมินผล
README.md : เอกสารอธิบายรายละเอียดโปรเจกต์

## 2. Dataset ที่ใช้
ข้อมูลที่เลือก: ชุดข้อมูลรูปภาพ (เช่น CIFAR-10, MNIST หรือ Dataset เฉพาะทางตามความเหมาะสม)
ลักษณะข้อมูล: แบ่งออกเป็นคลาสย่อยต่าง ๆ สำหรับงาน Image Classification โดยจะทำการแบ่งสัดส่วนข้อมูลออกเป็นชุดฝึกสอน (Training Set) และชุดทดสอบ (Testing Set) ก่อนเข้าสู่กระบวนการเตรียมข้อมูล

## 3. ขั้นตอนการดำเนินงาน (Workflow)วัตถุประสงค์ประยุกต์ใช้โครงข่ายประสาทเทียมแบบคอนโวลูชัน (CNN) ในการจำแนกประเภทข้อมูลรูปภาพ   เปรียบเทียบประสิทธิภาพการทำงานเมื่อปรับเปลี่ยนจำนวน Epochs และโครงสร้างเลเยอร์ของ CNN   

## 4. ผลลัพธ์ที่ได้ (Outputs)เมื่อรันโปรแกรมเรียบร้อยแล้ว ระบบจะสร้างและบันทึกผลลัพธ์การทดลองดังนี้:Accuracy Scores: ค่าคะแนนความแม่นยำของโมเดลในแต่ละสถาปัตยกรรม (CNN Configuration)   Epochs Comparison: การเปรียบเทียบผลลัพธ์ความแม่นยำเมื่อใช้จำนวนรอบการฝึกที่แตกต่างกัน   Training & Validation Curves: กราฟแสดงแนวโน้มของ Accuracy และ Loss ทั้งในช่วง Training และ Validation   Predictions: ตัวอย่างผลการทำนายภาพจากชุดข้อมูลทดสอบ
